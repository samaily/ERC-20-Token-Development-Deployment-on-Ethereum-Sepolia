# ERC-20-Token-Development-Deployment-on-Ethereum-Sepolia
An ERC-20 token built with Solidity and OpenZeppelin, developed in Remix IDE and deployed to the Ethereum Sepolia testnet. Features initial minting of 1,000 STK and wallet-to-wallet transfers using MetaMask.
